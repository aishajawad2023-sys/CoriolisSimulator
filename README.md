# Coriolis Physics Simulator

An interactive physics simulator exploring:

- Circular motion
- Linear velocity
- Angular velocity
- Centripetal acceleration
- Centripetal force
- Vertical circular motion
- Rotating reference frames
- Coriolis acceleration
- Centrifugal acceleration
- Earth's rotation
- Experimental data and graphs

## Technologies

- Python
- Pygame
- NumPy
- Matplotlib

## Current Stage

Currently implementing the basic circular-motion simulation.

## Physics

For uniform circular motion:

v = ωr

Centripetal acceleration:

a_c = v²/r

or:

a_c = ω²r

Coriolis acceleration:

a_C = -2(Ω × v)

## Controls

↑ ↓ — Change radius

← → — Change angular velocity

SPACE — Pause

R — Reset
